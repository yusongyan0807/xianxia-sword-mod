# 国风剑修美术与 3D 建模统一规范（Art Style Guide）

> **美术基准母版**：青锋御剑（`xianxia_placeholder:qingfeng_flying_sword`）  
> **维护职责**：常驻主美与 3D 视觉专员（`xianxia-art-director`）及双人协同开发者

本文档固化本模组长期迭代的**东方仙侠像素与 3D 器物视觉规范**，确保后续所有飞剑、本命法宝、背部剑匣、阵盘、粒子流光与 UI 界面与首版「青锋御剑」保持统一审美品质。

## 1. 视觉总纲与立体化原则

1. **器物气质**：俊逸修长、层次分明、古雅克制，采用**“寒铁映青玉，鎏金配朱穗”**的传统东方仙剑比例，拒绝廉价高饱和霓虹噪点与单薄 2D 纸片模型（`item/generated`）。
2. **多部件立体结构**：核心飞剑与法宝必须采用 Blockbench 多部件 3D JSON 结构，体现隆起剑脊、吞口箍环、飞檐斜角剑格与灵玉嵌核。

## 3. 纹素密度（Texel Density）与建模约束

1. **分辨率阶梯**：核心飞剑/剑匣/本命法宝统一 **`64×64` PNG**（JSON 内 `uv` 仍按 Minecraft `0..16` 归一化空间映射，`1` UV 单位对应 `4×4` 像素）；普通材料/玉简图标统一 **`16×16` / `32×32`**；采样一律保持 `NEAREST` 锐利像素边缘。
2. **原版旋转角约束**：每个 `element` 仅允许单轴（`x`/`y`/`z`）使用 `-45°`、`-22.5°`、`0°`、`22.5°`、`45°` 五种合法角度；连续飞行俯仰/横滚/悬浮动画统一交由客户端 `PoseStack` 插值实现。
3. **防穿模与防闪烁**：包覆部件（如 `blade_spine` 与 `blade_lower`）至少保留 `0.03 ~ 0.15` 厚度差杜绝 Z-fighting；脚底渲染层（`FlyingSwordRenderLayer`）预留潜行与正弦悬浮波谷安全间距，确保鞋底不穿入剑身。
4. **双人协同源文件约定**：Blockbench `.bbmodel` 原始工程文件统一存放于 `art/blockbench/` 纳入 Git 管理（`build.gradle` 已自动排除打包）。
