# 中国风剑修模组演进总蓝图与差异化设计（Roadmap & Design）

> **目标平台**：Minecraft `1.21.1` · NeoForge · 双人异地协同开发  
> **核心定位**：**剑修核心突破 + 轻量灵力破境底座**（深耕飞剑物理手感、子母剑阵与本命剑养成，拒绝繁琐炼丹坐牢与冗余废矿）

---

## 1. 差异化核心设计矩阵（全网竞品破局方案）

| 维度 | 本模组定稿设计 | 解决的同类模组痛点 |
| :--- | :--- | :--- |
| **御剑飞行架构** | 独立 `FlyingSwordEntity` + 站立踏剑姿态渲染 + **「精准悬停 / 破空剑遁（未加载区块自动凝剑防撞 + 撞山弹反）」双模态切换** | 彻底解决竞品“超音速撞墙暴毙”与“盖房挖矿无法精准悬停”痛点 |
| **多人联机亮点** | **双人共乘“灵剑化巨”**：悬停时好友右键共乘，飞剑矩阵平滑放大 `1.6x`，后座可自由射箭/施法/御剑 | 填补主流御剑模组无原生双人同乘一剑的联机空白 |
| **装备与扩容** | 接入 **Curios API** 动态飞剑饰品槽：随大境界突破通过属性修饰符自动增加飞剑槽位数，背后实时悬浮/空位渲染 | 不抢占原版靴子护甲位，完美融入现代 RPG 整合包生态 |
| **极简神识操控** | **双键（`G` 踏剑 / `R` 神识）+ 水墨八卦轮盘**：常态环绕护体劈箭；短按 `R` 指怪穿刺 / **指远处掉落物隔空挑回手中**；长按 `R` 轮盘切阵 | 降维打击竞品八九个组合键“弹钢琴式”繁琐操作 |
| **1+N 本命养成** | 1.21.1 `DataComponents` 唯一温养 **1 把本命母剑**（永不淘汰）；**任意原版/他模组剑皆可作子剑共鸣染上母剑五行流光**；终极禁术可**献祭廉价子剑殉爆**（母剑不损） | 根治多把剑重复肝词条痛点，盘活原版过剩铁/钻石与淘汰旧武器 |
| **境界与材料生态** | 四大质变境界（`炼气1剑 → 筑基3剑 → 剑丹6剑 → 元婴9剑`）+ `1.21.1 DataMap` 零废矿原版材料喂剑 + **雷雨天“插剑引雷”60 秒动作渡劫** | 零世界生成污染、零挂机打坐读条，整合包魔改极度友好 |
| **动画与特效栈** | Blockbench 标准 3D 模型 + 弹簧阻尼程序化物理轨迹插值 + 自定义顶点剑气拖尾（Ribbon Trail） | 原生兼容所有原版/外部模组子剑流光渲染，高帧率、无 GeckoLib 强依赖 |

## 2. 分阶段里程碑路线图

- **`v0.1.0`（已完成 — 最小验证原型）**：项目立项与占位符规范、NeoForge 1.21.1 标准环境、16 部件「青锋御剑」3D 模型与 `64×64` 贴图、脚部槽位装备与御剑飞行闭环、全套单元测试与 GameTest 验证。
- **`v0.2.0`（御剑实体化与双人共乘）**：实现 `FlyingSwordEntity`、玩家踏剑站立姿态覆盖、「精准悬停 / 防撞剑遁」双飞行物理模式及双人共乘巨剑缩放同步。
- **`v0.3.0`（Curios 剑匣与双键神识战斗）**：接入 Curios 飞剑饰品栏与背部动态渲染，实装 `R/G` 双键交互、护体劈箭、飞剑隔空取物、准星集火穿刺与水墨八卦轮盘。
- **`v0.4.0`（本命母剑进化与子母剑阵）**：实装 `DataComponents` 本命剑品阶与五行剑意温养、原版/跨模组子剑同调染色、顶点刀光拖尾及「碎子剑·一剑开天门」禁术。
- **`v0.5.0`（四大剑道境界与引雷渡劫）**：实装 `AttachmentType` 灵力底座、`DataMap` 万物喂剑配方以及雷雨天插剑引雷 60 秒试剑破境仪式。
